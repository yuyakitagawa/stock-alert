#### インタビュー要旨（ペルソナ8名: 初心者スマホ/GARP中級/デイトレ/英語圏/リピーター/シニア/SEO視点/モバイル回遊）
1. **記事を読んでいる瞬間に「この投資家は乗っかって儲かる相手か」が分からない**（初心者・リピーター）。
   実績（filer_win_rate）は投資家ページと/rankingにあるが、記事内の投資家名の横には出ない。
   タップして往復するのは面倒→記事内に実績チップを出してほしい。
2. 銘柄ページの提出投資家リストも同様に、名前と分類バッジだけで強弱の判断材料が無い（GARP中級）。
3. ウォッチリストが無い。気になる投資家・銘柄を保存して再訪したい（リピーター）→次サイクル候補。
4. 英語版は投資家一覧・ランキング・週次まとめが無く回遊が浅い（英語圏）→大型のため据え置き。
5. データの更新タイミング（何時に今日の開示が載るか）が分からない（デイトレ）→小型、次サイクル候補。
