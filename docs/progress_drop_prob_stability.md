# 下落確率の水準安定化 進捗

## 背景（2026-09-19 調査）
- 金曜の再学習ごとに、全銘柄の平均下落確率が大きく上下する（週平均: 8/3週 11.9% → 9/7週 4.5% → 9/14週 10.1%）。
  「🔴 売り検討」(drop_prob≥10%) の銘柄割合が 12%〜44% で揺れる。
- 銘柄の並び順はほぼ不変（再学習をまたいだ順位相関 0.94〜0.99）＝目盛りだけが伸縮している。
- 過去予測の較正は概ね妥当（3〜6月の予測 約2.5万件: 予測9.0%→実績8.4%、11.7%→10.3%、31.5%→31.4%）。
  よって絶対値の閾値（10%）は維持し、学習側の水準のぶれを減らす方針（オーナー確認済み。順位ベース案は却下）。
- 原因候補:
  1. `train_model()` が毎回、Focal Loss / SMOTE+ENN / アンダーサンプリング / LGBアンサンブルを F1 差 0.001〜0.005 で自動採用 → 週ごとに作り方が変わる
  2. 早期打ち切り（eval_set）と作り方の選択が、どちらもテストセット `X_te` を使っている（`core/rf_train_v3.py` 378行目付近）→ AUCが楽観的 & 選択がノイズ
  3. 同じ作り方（XGB+LGB平均）の週どうしでも平均は 11.9%→4.5% まで動いた＝1だけでは説明しきれない
- テストAUC推移: 8/28 0.764 → 9/4 0.753 → 9/11 0.742 → 9/18 0.713
