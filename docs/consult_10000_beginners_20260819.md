# 投資初心者10,000人 グループワーク コンサル（2026-08-19）

前回（`consult_1000_investors_20260819.md`）は10セグメント混合1,000人。今回は**全員が投資初心者**の
10,000人（20グループ×500人）に絞り、「株を始めて1年未満の人がこのサイトに来て、
最初の3分で何が分かって何が分からないか」だけを論点にした。

## 0. 実施方法（正直な前提）

- 実在ユーザー調査ではなく**AIによる仮想グループワーク**。ただし仮想の声を出す前に、
  **実データ・実コードで裏が取れた欠陥だけ**を第1章のテーブルに載せている。
- 今回の環境では本番サイト（kujira-watch.com）へのHTTPアクセスが**エグレス制限で遮断**されていたため、
  監査は「現行コード（main HEAD = 96e784f）」＋「Supabase実データ」で行った。
  実ブラウザでの目視確認（レイアウト崩れ・CLS等）は含まない。
- 対象は**フロント／記事生成／導線のみ**。買いフィルター・特徴量などモデル本体は対象外（CLAUDE.md 準拠）。

## 1. 事前監査で確認された「事実」（仮想の声ではない）

### 1-A. スマホの初見に、サイトの説明が1文字も無い（初心者特有・最重要）
TOPの `<h1>` は「**注目の取引**」（`src/app/(ja)/page.tsx:51`）。サイトが何をする場所かの説明は
ヘッダーのキッカー「EDINET大量保有報告書から読む大口投資家の動き」だけだが、これは
`Header.tsx:95` で `display: { xs: "none", sm: "block" }` = **スマホでは非表示**。
「このサイトについて」への導線はハンバーガーとフッターのみ（`HeaderMenu.tsx:95` / `Footer.tsx:34`）。
つまりスマホの初見ユーザーが見るのは「🐋 サイト名」と「注目の取引」と数字だけで、
**"大量保有報告書とは何か"に触れないままカード一覧に落ちる**。「はじめての方へ」に相当するページも無い。

### 1-B. 初心者が最初に見るリストの約3割が「参考にならない開示」
直近14日の開示601件の内訳（`edinet_large_holdings` × `edinet_filer_classification`）:

| 提出者カテゴリ | 件数 | 比率 |
|---|---|---|
| 個人 | 110 | 18.3% |
| **日系証券銀行** | 105 | **17.5%** |
| 事業会社 | 81 | 13.5% |
| その他 | 77 | 12.8% |
| アクティビスト | 75 | 12.5% |
| 国内アセットマネジメント | 56 | 9.3% |
| 外資系伝統運用会社 | 41 | 6.8% |
| PE・メザニンファンド | 24 | 4.0% |

単独トップの提出者は**野村證券（59件＝全体の9.8%）**、次いで三井住友トラスト・AM（18件）。
これらはプライムブローカー的・機械的な提出で、FAQ（terms「プライムブローカーの保有は投資判断と
みなせますか？」）では「投資判断ではない」と説明しているのに、**一覧・記事側では他と同じ扱いで並ぶ**。
初心者は「野村證券が買った＝プロが買った」と読む。

### 1-C. 「この投資家は誰？」に7割で答えられない
`edinet_filer_classification` 2,950件のうち `profile` が埋まっているのは **813件（27.6%）**。
直近14日の開示601件のうち **178件（29.6%・提出者115人分）がプロフィール無し**。
記事から投資家ページへ飛んでも、初心者が一番知りたい「何者か」が空欄。

### 1-D. 投資家一覧が「初心者が有名な人を探せない」構造
`edinet_filer_summary` 2,950人のうち、開示**1件のみ**が995人（33.7%）、2〜4件が1,329人、5件以上は626人。
カテゴリは「個人」が1,362人（46.2%）で最多、アクティビストは**51人（1.7%）**。
初心者が知りたいのは後者51人だが、一覧では単発の個人名に埋もれる。

### 1-E. 記事タイトルの投資家名が全角のまま＋60字で機械的に切られる
`build_article_titles()`（`web/publish_blog_articles.py:757`）は生の `filer_name` を使う。
フロントには全角→半角の表示用ヘルパー `displayFilerName()`（`src/lib/format.ts:71`）があるが、
**タイトルには適用されていない**。直近30日のユニーク（提出者×銘柄）859件のうち
**242件（28.2%）が全角英字の提出者名**、**117件（13.6%）は60字上限を超えて `…` で切られる**計算。
一覧カードで「Ｌｏｎｇ　Ｃｏｒｒｉｄｏｒ　Ａｓｓｅｔ　Ｍａｎ…」のような表示になる。

### 1-F. 前回コンサルの1位・3位が未着手のまま（初心者が最大の被害者）
- `ratio_change_pct()`（`publish_blog_articles.py:530`）の「前回比率が無ければ今回比率＝新規取得」
  フォールバック、`is_new_holding()`（同 737）の同フォールバックは**そのまま残っている**。
- フロントも `article.ratioChangePct` をEDINETスナップショットより優先する実装のまま
  （`src/app/(ja)/articles/[id]/page.tsx:189`）。「保有比率10.57%（前回10.72%）」と「前回比 −10.57pt」の
  同時表示が起きる状態が継続。
- 発生源の実測: 直近14日の**変更報告書520件のうち9件（1.7%）が `holding_ratio_prior` NULL** で取り込まれている。
  率は低いが、この9件は「新規保有」＋金額過大として**注目枠・日次合計・X投稿の上位に来る**ため被害は率に比例しない。
  中級者は前回比率を見て矛盾に気づくが、**初心者は気づかずそのまま信じる**。

### 1-G. 記事末尾CTAの3チャネルのうち、実質1.5チャネルしか動いていない
`FollowCta.tsx` は LINE / X / YouTube の3ボタンを出す（LINEは環境変数未設定なら非表示）。実データ:

| チャネル | 実績 |
|---|---|
| X | `x_posts` テーブルが**全期間0行**（記録が一件も無い）。直近コミットは 8588d7c「401/403時にトークン権限をログ出力」、c19e0cd「Xトークン権限の手動確認ワークフロー」＝**投稿が通っていない疑いが濃厚** |
| LINE | `line_users` **1件**（実質オーナーのみ）。`NEXT_PUBLIC_LINE_ADD_FRIEND_URL` 未設定ならボタン自体が出ない |
| YouTube | 稼働中（`video/publish_video.py`） |

CTA本文は「公式X（@…）でも**毎日お知らせしています**」と断言している。投稿が止まっているなら
**記事の中で事実と違うことを言っている**ことになる。

### 1-H. 回遊がほぼ無い（※ボット混在のため参考値）
`blog_crawler_log` の `bot_name='Browser'`（直近30日）: 訪問者7,456のうち**6,268（84.1%）が1ページのみ**。
6ページ以上が1,171と二峰性で、明らかに未ラベルのボットが混じっているため絶対値は信用しない。
ページ別PV上位は `/articles/*`（15,679）→ `/en*` → `/stocks/*` → `/investors/*` → `/`。
**入口は記事、しかし記事から次に行っていない**という形は前回と変わらない。
公開カウンタ（`blog_visit_counter`）は累計2,446。

### 1-I. その他（初心者視点で確認できた事実）
- 「開示後の株価推移」は直近14日の対象408銘柄中**392銘柄（96.1%）で株価が引ける**＝ほぼ表示される。
  ただし新しい記事は1ヶ月後・3ヶ月後が空欄で、**いつ埋まるかの説明が無い**（前回11位・未着手）。
- 記事本文は中央値445字（`publish_blog_articles.py:953` のコメント）で、末尾に必ず「※推測:」文が入る。
- FAQ basics は20問超と充実しているが、**記事・TOPからの用語リンクが「実際の売買とのずれ」1本だけ**。
  「pt」「変更報告書」「保有比率」「前回比」はその場で説明されない。
- 免責は `/about`・ドロワー最下部・記事下部に分散。初心者が最も欲しい「これは買い推奨ではない」は
  ドロワーを開かないと読めない。

## 4. 今日やるべき3点（コンサル結論）

1. **1行の自己紹介をTOPに出す（スマホ含む）**。工数は最小で、10,000人の最多票。
   今は「何のサイトか」を説明しないまま数字を見せており、初心者の離脱はここで起きている。
2. **「新規保有」誤記の発生源を止める**（前回1位・未着手）。中級者は矛盾に気づくが初心者は信じる分、
   初心者向けサイトとしては被害が大きい。直近14日で該当9件と量は少なく、修正は小さい。
3. **X投稿の停止を確認して、CTAの文言を実態に合わせる**。`x_posts` が全期間0行で、
   記事は「毎日お知らせしています」と書いている。復旧が先だが、復旧できないなら文言を先に直す。
