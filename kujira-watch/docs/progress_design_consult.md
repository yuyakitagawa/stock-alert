# kujira-watch デザインコンサルレビュー・改善 進捗（2026-08-15）

外部ネットワーク遮断環境のため、本番Supabaseの実データ抜粋＋microCMS/PostgREST互換モック
（セッションのscratchpad、コミット対象外）でローカル再現し、Playwrightで375px/1280px × ja/en の
全主要ページを目視監査した。

## デザインレビュー: kujira-watch 全体

### P1（実害あり: 可読性・視認性）
- [x] **注目カードの文字衝突**: アイキャッチには白太字の事実テキスト（方向・提出者・銘柄）が
  焼き込まれており、`FeaturedArticleCard` は画像opacity 0.7＋弱いグラデの上にタイトル・抜粋を
  重ねるため、中段で焼き込みテキストとカード文字が二重表示になり判読不能。
  → 画像opacityを下げ、スクリム（#16213a系グラデ）を強化。
- [x] **注目カード上の分類バッジが読めない**: `DEAL_TYPE_COLORS.text` はライト背景用
  （例: その他=rgba(32,29,26,.6)）で、ダーク地の注目カードではWCAG大幅未達。売りバッジ
  （error.main）も同様。→ `DealTypeBadge`/`DealDirectionBadge` に `onDark` を追加
  （文字白・ドットのみ分類色）。
- [x] **モバイルヘッダーのロゴ3行折返し**: 375pxで「クジラウォッチ」「Big Investor Watch」が
  3行に折れブランドが壊れて見える。原因は右側の検索＋累計訪問者数＋メニューによる幅不足。
  → ロゴ `white-space: nowrap`、訪問者数カウンターはxs非表示（sm以上のみ）。
- [x] **記事詳細の分類バッジ二重表示**: `DealTypeBadge`（ドット）と `CategoryBadge`（Chip）が
  同一ラベルで並ぶ（ja/en両方）。直下に説明文＋「分類の一覧を見る」もあり冗長。
  → ドット版を削除しリンク付きChipに一本化。

### P2（一貫性・洗練）
- [x] **ランキングの巨大金額**: 「+107,900.0億円」。兆換算が無く桁が読めず列を圧迫。
  → 1万億円以上は「+10.8兆円」表記（`formatAmountParts`）。/weeklyの金額タイルも共用。
- [x] **EDINET全角英数の表示**: 「ＢＣＰＥ　Ｐａｎｇｅａ…」等が全ページで読みにくい。
  → 表示専用 `displayFilerName()`（全角英数→半角、リンクhref・DB照合は原文維持）を
  ranking / investors一覧 / investors詳細 / trending / 記事メタに適用。
- [x] **/weekly統計タイルの数字折返し**: 「4,083億円」がh4で2行に折れタイル高が不揃い。
  → 数字＋単位を分離（左タイルと同じ構造に統一）し、兆換算も適用。
- [x] **投資家一覧の行レイアウト揺れ**: flex-wrapで分類ラベルの位置が行ごとに変わる。
  → 1行目=名前 / 2行目=分類＋開示メタ の2行構造に統一。

### P3（見送り・理由）
- 銘柄ページ株価チャートの面塗り: 効果が薄く既存Chartの簡潔さを優先して見送り。
- /rankingの長い前置き: SEO/初見者向け説明の意図があるため文言・構成は現状維持。
